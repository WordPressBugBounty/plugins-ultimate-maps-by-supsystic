== Description ==

**Ultimate Maps by Supsystic** is a WordPress map plugin for interactive OpenStreetMap maps built on Leaflet. Add unlimited maps and markers, describe each place with text, photos and video, group markers into categories with a filter and cluster them when they crowd together. It works out of the box without a Google Maps API key, and your pages make no requests to Google.

Want a different look? Switch the same map to Mapbox, Thunderforest, Bing Maps or your own tile server without rebuilding a single marker.

**Try it in your browser:** [open a live demo in WordPress Playground](https://playground.wordpress.net/?plugin=ultimate-maps-by-supsystic) – no install, no account.

= OpenStreetMap without an API key =

OpenStreetMap tiles load through Leaflet with no key and no account. Pick the style that suits your site:

* OpenStreetMap Standard, Germany and Humanitarian
* OpenTopoMap, CyclOSM and OpenHikingMap for outdoor, cycling and hiking maps
* Public transport and railway maps
* OpenFreeMap vector styles: Positron, Bright, Liberty, Dark and Fiord
* CartoDB Positron

= More map providers =

* Mapbox: streets, outdoors, light, dark and satellite (free access token)
* Thunderforest: OpenCycleMap, outdoors, landscape and transport (free API key)
* Bing Maps: road, aerial, bird's eye and canvas (Bing Maps key)
* MapTiles API (OpenStreetMap) through RapidAPI
* Any custom or self-hosted Leaflet tile server

Change the provider of an existing map at any time. Your markers stay where they are.

== Installation ==

1. In your dashboard go to Plugins → Add New Plugin and search for "Ultimate Maps by Supsystic".
2. Click Install Now, then Activate.
3. Open the Ultimate Maps menu and add a new map. OpenStreetMap works right away, no key needed.
4. Add markers by typing an address or clicking on the map, then save.
5. Add the map to a page with the block, the Elementor widget or the shortcode.

== Frequently Asked Questions ==

= Do I need an API key? =

No. OpenStreetMap maps through Leaflet work without any key or account. Mapbox, Thunderforest, Bing Maps and MapTiles API need a key from that provider; Mapbox and Thunderforest offer free plans.

= Is it a Google Maps alternative? =

Yes. Ultimate Maps gives you interactive maps with markers, categories and clustering without Google Maps, a Google API key or Google billing.

= Does the plugin send data to Google? =

No. Ultimate Maps makes no requests to Google. Tiles load only from the map provider you select.

= Can I switch the map provider later? =

Yes. Change the provider or style of an existing map at any time, and your markers stay in place.

= How many maps and markers can I add? =

As many as you need. Maps and markers are unlimited in the free plugin.

= Can I use my own marker icons? =

Yes. Choose an icon from the built-in library or upload your own image.

= Can visitors filter markers by category? =

Yes. Assign markers to categories and show a front-end filter on the map.

= Does it support marker clustering? =

Yes. Nearby markers group into clusters that open as visitors zoom in.

= Can I move my maps from Easy Google Maps? =

Yes. Ultimate Maps imports maps from our Easy Google Maps plugin. You can also move maps and markers between sites with CSV import and export.

= How do I add a map to a page or post? =

Use the plugin's block in the block editor, the Elementor widget, the sidebar widget, or paste the map shortcode. A PHP snippet is available for theme templates.

= Can I draw areas or routes on the map? =

Polygons, polylines and circles are available in Pro, along with KML layers and a heatmap.

= Is the plugin translation-ready? =

Yes. The plugin is translation-ready and ships with a German translation.

= How can I report a security issue? =

Please report security issues through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/9e5fb555-5627-47cf-a701-78547bbb5e53). The Patchstack team validates and triages each report and notifies us.
